# Review System

投资能力不是由“看过多少内容”决定，而是由错误能否被识别和修正决定。

这里维护三类反馈：

1. **Knowledge Error** — 不知道
2. **Reasoning Error** — 知道知识，但推理错
3. **Decision Error** — 分析可能正确，但仓位、时机或执行错误

另外单独标记：

- Language Error
- Calculation Error
- Data Error
- Bias / Emotion

## 核心原则

**Outcome ≠ Decision Quality**

一笔赚钱交易可能违反规则；一笔亏钱交易也可能是合理决策。

## 什么时候复盘

不要求固定周 / 月节奏。出现这些节点时做 Milestone Review：

- 完成一个 CFA / CPA 知识模块；
- 完成一家公司研究；
- 一个重要 thesis 被验证或证伪；
- 完成一次完整 Mock；
- 出现重复错误；
- 一个持仓逻辑发生实质变化。
