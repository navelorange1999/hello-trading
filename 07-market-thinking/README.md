# Market Thinking

目标：从“新闻 → 看多/看空”的直觉反应，升级到“事实 → 预期 → 价格 → 预期差”。

## 核心公式

市场反应通常不取决于事情“好不好”，而取决于：

**实际结果 - 市场预期**

所以每次看事件先拆四层：

1. Fact：发生了什么？
2. Consensus：市场原本预期什么？
3. Price-in：价格已经反映多少？
4. Delta：新的信息改变了什么？

## 事件驱动训练

不按固定周期做练习。遇到值得研究的节点时填写 Expectation Gap，例如：

- 财报
- 宏观数据
- 政策
- 商品供需
- 行业数据
- 重大公司事件
- 突发事件
- 市场价格与基本面出现明显背离

## 少问这些问题

- “这个新闻利好吗？”
- “明天会涨吗？”

## 多问这些问题

- “这条信息相对市场预期新增了什么？”
- “如果价格不涨，说明市场之前预期了什么？”
- “什么二阶影响可能被忽略？”
- “价格反应本身告诉了我什么？”
