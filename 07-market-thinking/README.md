# Market Thinking

目标：从“新闻 → 看多/看空”的直觉反应，升级到“事实 → 预期 → 价格 → 预期差”。

## 核心公式

市场反应通常不取决于事情“好不好”，而取决于：

**实际结果 - 市场预期**

所以每次看事件先拆四层：

1. Fact：发生了什么？
2. Consensus：市场原本预期什么？
3. Price-in：价格已经反映多少？
4. Delta：新的信息改变了什么？

## 每周训练

每周至少做一次 Expectation Gap：

- 财报
- 宏观数据
- 政策
- 商品
- 行业供需
- 突发事件

## 禁止问题

少问：
- “这个新闻利好吗？”
- “明天会涨吗？”

多问：
- “这条信息相对市场预期新增了什么？”
- “如果价格不涨，说明市场之前预期了什么？”
- “什么二阶影响可能被忽略？”
