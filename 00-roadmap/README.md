# Roadmap

> 主线：CFA Level I。副线：CPA《会计》。实践线：真实公司、预期差、复盘。

这个 Roadmap **不按固定周数推进**。每个节点的完成条件是“理解 + 做题 + 实践 + 复盘”，而不是“花了多少时间”。

---

## Node 0 — Baseline & Orientation

目标：建立起点，并确认当前最需要补什么。

### CFA
- Financial Statement Analysis 基础
- Equity 基础
- Corporate Finance 基础
- Economics 基础

### CPA
只补与当前 CFA 知识直接相关的会计问题。

### 输出
- 1 份公司研究
- 1 次混合题测试
- 建立 Error Log

### 完成标准
- 能看懂 CFA 题目语言
- 知道自己最弱的知识域
- 能解释“财报 / 估值 / 宏观 / 风险”分别解决什么问题

---

## Node 1 — Company & Financial Statements

### CFA
- Financial Statement Analysis

### CPA
- 收入确认
- 存货
- 固定资产 / 无形资产
- 资产减值
- 所得税

### 实战
- 拆一家熟悉公司的三大报表
- 对比净利润与经营现金流
- 计算 ROE / ROIC / FCF
- 找出主要会计判断与利润质量风险

### 完成标准
- 能解释三张报表如何联动
- 能指出利润和现金流不匹配的常见原因
- 能识别常见盈利质量问题
- 完成一份 Investment Note

---

## Node 2 — Equity & Corporate Finance

### CFA
- Equity
- Corporate Finance

### CPA
- 长期股权投资
- 企业合并
- 商誉
- 合并报表

### 实战
- PE / PB / EV/EBITDA / FCF Yield
- 简化 DCF
- 估值敏感性
- 资本配置
- 市场隐含预期

### 完成标准
- 能解释不同估值方法适用什么公司
- 能拆解 ROIC 与资本成本
- 能解释“好公司为什么不一定是好投资”
- 能写出一个明确的 expectation gap

## Node 3 — Economics & Fixed Income

### CFA
- Economics
- Fixed Income

### 实战
- 通胀、增长、利率与估值
- 收益率曲线
- Duration
- 信用风险
- 宏观事件的 Fact / Consensus / Price-in / Surprise

### 完成标准
- 能解释债券价格与收益率关系
- 能解释利率变化如何影响不同资产
- 能分析一个宏观事件的预期差
- 能区分一阶与二阶影响

---

## Node 4 — Quant & Portfolio

### CFA
- Quantitative Methods
- Portfolio Construction

### 工程实验
- 收益率、波动率、相关性
- 回归
- 组合风险
- 最大回撤
- 仓位与情景分析

### 完成标准
- 能解释相关性为什么影响组合风险
- 能理解回归输出在投资中的含义
- 能对自己的持仓做基本风险诊断
- 能说明“高收益”和“好组合”为什么不是一回事

---

## Node 5 — Derivatives, Alternatives & Ethics

### CFA
- Derivatives & Risk Management
- Alternative Investments
- Ethics

### 完成标准
- 能解释 Futures / Forward / Option / Swap 的核心差异
- 能说明 hedging 与 speculation 的区别
- 能理解另类资产在组合中的角色
- Ethics 题目达到稳定理解而非死记

---

## Node 6 — Integration

目标：把分散知识连接成完整投资流程。

### 综合练习
选择一家真实公司，完整走一遍：

**Business → Industry → Financials → Capital Allocation → Valuation → Expectations → Risk → Decision**

### 完成标准
- 能独立完成完整 Investment Note
- 能解释关键假设
- 能写出 falsification conditions
- 能指出自己最不确定的部分
- 能区分事实、假设、推断和市场预期

---

## Node 7 — CFA Registration Gate

完成以下条件后，再考虑报名：

- [ ] Level I syllabus 第一轮完成
- [ ] 章节题大部分已做
- [ ] 至少 2 次完整模拟
- [ ] 英文阅读基本不依赖翻译
- [ ] 至少 4 份 Investment Note
- [ ] Error Log 已形成稳定分类
- [ ] 能说清楚自己的 3 个薄弱 Topic

---

## Node 8 — CFA Exam Mode

一旦正式报名，目标从“扩展认知”切换为“通过考试”。

- CPA 暂停或极低频
- 公司研究降频
- 以 Mock、错题、薄弱模块、Ethics 为核心
- 重复：Mock → Error Log → Weak Topics → Targeted Practice → Mock

完成标准只有一个：

> 在考试条件下，知识调用速度和准确率足够稳定。

---

## 建议知识顺序

1. Financial Statement Analysis
2. Equity
3. Corporate Finance
4. Economics
5. Fixed Income
6. Quantitative Methods
7. Portfolio Construction
8. Derivatives
9. Alternative Investments
10. Ethics（全程穿插，后期强化）

这个顺序是**建议依赖关系**，不是时间表。遇到现实问题时可以跳转节点，再回到主线。
