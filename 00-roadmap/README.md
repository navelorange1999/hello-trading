# Roadmap

> 主线：CFA Level I。副线：CPA《会计》。实践线：真实公司、预期差、复盘。

## Phase 0 — 试学与基线测试（2–4 周）

目标：确认自己喜欢这套学习，并建立基线。

- CFA：Financial Statement Analysis、Equity、Corporate Finance、Economics
- CPA：只补与 CFA 同主题相关的会计知识
- 输出：1 份公司研究、1 次 50 题混合测试、1 份 Error Log

## Phase 1 — 公司与财报（6 周）

### CFA
- Financial Statement Analysis

### CPA
- 收入确认
- 存货
- 固定资产 / 无形资产
- 资产减值
- 所得税

### 实战
- 拆一家熟悉公司的三大报表
- 对比净利润与经营现金流
- 计算 ROE / ROIC / FCF

完成标准：
- 能解释三张报表如何联动
- 能指出利润质量的主要风险
- 完成 Investment Note #1

## Phase 2 — 公司金融与权益投资（6 周）

### CFA
- Equity
- Corporate Finance

### CPA
- 长期股权投资
- 企业合并
- 商誉
- 合并报表

### 实战
- PE / PB / EV/EBITDA / FCF Yield
- 简化 DCF
- 估值敏感性
- 市场隐含预期

完成标准：
- 完成 Investment Note #2
- 能解释“好公司为什么不一定是好投资”

## Phase 3 — 宏观与利率（8 周）

### CFA
- Economics
- Fixed Income

### 实战
- 通胀、利率、增长与估值
- 收益率曲线
- Duration
- 信用风险
- 每周一次 Macro Expectation Gap

## Phase 4 — Quant 与组合（7 周）

### CFA
- Quantitative Methods
- Portfolio Construction

### 工程实验
- 收益率、波动率、相关性
- 回归
- 组合风险
- 最大回撤
- 仓位与情景分析

## Phase 5 — 补齐资产地图（4 周）

### CFA
- Derivatives & Risk Management
- Alternative Investments
- Ethics 持续穿插

## Phase 6 — 报名 Gate

先完成以下条件，再考虑报名：

- [ ] syllabus 第一轮完成
- [ ] 章节题大部分已做
- [ ] 2 次以上完整模拟
- [ ] 英文阅读基本不依赖翻译
- [ ] 4 份以上 Investment Note
- [ ] Error Log 已形成稳定分类
- [ ] 能说清楚自己的 3 个薄弱 Topic

## Phase 7 — CFA Exam Mode（8–12 周）

报名后：
- CPA 暂停
- 公司研究降频
- 90% 时间投入 CFA
- Mock → 错题 → 薄弱模块 → 再 Mock

## 建议学习顺序

1. Financial Statement Analysis
2. Equity
3. Corporate Finance
4. Economics
5. Fixed Income
6. Quantitative Methods
7. Portfolio Construction
8. Derivatives
9. Alternative Investments
10. Ethics（全程少量 + 冲刺强化）
